# Reglas del proyecto

- Usa siempre el navegador integrado de Codex para abrir, inspeccionar y comprobar páginas web de este portafolio, tanto en local como en staging o producción.
- Toda pantalla, componente o pieza nueva debe seguir `docs/design-system.md`. Reutiliza los tokens y componentes existentes antes de crear otros; si hace falta ampliarlos, actualiza también el sistema.
